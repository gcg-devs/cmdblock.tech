## ADDED Requirements

### Requirement: Homepage search and social metadata
The homepage SHALL expose high-quality metadata for search engines and social platforms without altering rendered homepage content.

#### Scenario: Metadata exists without UI changes
- **WHEN** the homepage is rendered
- **THEN** metadata includes an SEO-oriented title and description for the portfolio
- **THEN** Open Graph and Twitter metadata represent the same homepage intent
- **THEN** visible homepage sections and copy remain unchanged
